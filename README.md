XenoState optimizes distributed system performance via High-Performance, Scalable architectures Learning Integration within an Agent Framework and State Manager.

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/XenoState.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

XenoState is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
